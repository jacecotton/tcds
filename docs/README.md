* Copy-editing
  * These aren't hard and fast find &amp; replace rules, but might be substitutions worth considering if the guideline itself shouldn't be considered absolute:
    * "helps ensure" -> "can help"
    * "do not", "never" -> "avoid"
    * "please", "always" -> "prefer", "aim for", "maintain", "opt for"
  * At the same time, don't hedge unnecessarily, especially if it hurts concision and clarity.

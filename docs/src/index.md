Built using the Design System, this website serves as its living documentation. It provides live component examples with code snippets, and dynamically populates design information from our source files, ensuring the information presented here is accurate and up to date.

## Principles
Texas Children's Design System is...

**Downstream.** It implements and enforces our brand for the web, while meeting technical requirements for web users. It is not a general brand guideline and does not set the rules — it follows and documents them.

**Constrained.** It narrowly focuses on enabling the efficient development of quality, compliant web experiences for the specific needs of Texas Children's. It is not a general purpose design system like Google's Material, nor a frontend library like Tailwind.

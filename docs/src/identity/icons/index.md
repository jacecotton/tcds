* We should try to stay away from generic icon names and encourage establishing consistent meanings for all icons. For instance rather than "hamburger" we should call it "menu"; rather than "magnifying glass" we should call it "search". This way a single icon is less likely to have inconsistent implied meanings. This is especially true of illustrations.
* **Avoid using icons by themselves.** Icons cannot be guaranteed to have universally well-understood meaning ([1](https://www.nngroup.com/articles/icon-usability/ "Icon Usability - Nielsen Norman Group")).
* **Ensure icons are meaningful and relevant.** An icon should, to the extent possible, independently and accurately reflect the sense of the accompanying text. Deduce the context-dependent [icon classification](https://www.nngroup.com/articles/classifying-icons/) (resemblance, symbolic, or conventional), and consider whether an icon of a different classification may be more effective.

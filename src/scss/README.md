## Stylesheet bundle

This directory contains our base styles.

> **Note:** This directory does not contain component styles. Those are instead found in the [`components`](../components/README.md) directory, as per the [Single Directory Components](https://www.drupal.org/docs/develop/theming-drupal/using-single-directory-components) architecture. Components use these styles as a dependency.

### `tcds.scss` vs `shared.scss`
`tcds.scss` is for direct consumption of the Design System's stylesheet bundle.

`shared.scss` is for *shadow DOM adoption* of Design System styles that should be shared across components. It excludes things that already pierce through shadow boundaries — custom properties, `@font-face` definitions, etc. And because it's explicitly opt-in, it does not wrap the styles in `@layer`s.

`shared.scss` is compiled to (from root) `dist/css/shared.css`, and then in JavaScript, gets imported and re-exported as a `CSSStyleSheet` object by `src/components/_shared/styles/index.js`.

### `@layer` setup
`tcds.scss` wraps all styles in the following layers:

| Position | Name | Description |
| -------------- | ---- | ----------- |
| 1 | `tcds-props` | `--tcds`-prefixed custom properties, `@font-face` definitions, and `@keyframes` definitions |
| 2 | `tcds-side-effects` | Global styles to base HTML elements |
| 3 | `tcds-utilities` | Utility classes (non-namespaced, opt-in, `!important`-flagged) |

While the stylesheet layers them in order of the above positions, any stylesheet that is loaded *before* `tcds.css` can reorder and splice as needed, e.g.:

```css
@layer tcds-fonts, tcds-props, legacy-side-effects, tcds-side-effects, tcds-utilities, legacy-utilities;
```

This can help more easily control integration of the Design System within legacy or multi-design system codebases.

> **Remember:** All unlayered CSS will take precedence over layered CSS, so if a downstream codebase has unlayered styles, the Design System may not take full effect.

### Directory structure
Styles are organized as any of the following types:

| Name | Description | Organization | Barrel |
| ---- | ----------- | ------------ | ------ |
| `props` | `--tcds`-prefixed custom properties | Layered under `tcds-props`, located in `**/_props.scss` files | `./_props.scss` |
| `theming` | Global styles to base HTML elements | Layered under `tcds-side-effects`, located in `theming/**` | `./theming/_index.scss` |
| `utilities` | Utility classes | Layered under `tcds-utilities`, located in `**/_utilities.scss` | `./_utilities.scss` |
| `gen` | Generated files ([see below](#_gen-files)) | Located in `_gen/**` | None |

### `_gen` files
Some styles are generated by our build script rather than authored directly, due to the source of truth being something other than Sass/CSS. These are gitignored but you will see them if you build the Design System yourself.

| File | Source of truth | Build step | Description |
| ---- | --------------- | ---------- | ----------- |
| `_gen/_animations.css` | `src/tokens/motion/animation.json` | `build:tokens` | `@keyframe` definitions from [keyframe-formatted](https://developer.mozilla.org/en-US/docs/Web/API/Web_Animations_API/Keyframe_Formats) JSON objects |
| `_gen/_icons.css` | `src/images/icons/**/*.svg` | `build:images` | `--tcds-icon`-prefixed custom properties with `url()` values of SVG icons encoded as data URIs |
| `_gen/_tokens.css` | `src/tokens/**/*.json` | `build:tokens` | All JSON tokens output as `--tcds-` prefixed custom properties (excluding keyframe animations) |
| `_gen/_tokens.scss` | `src/tokens/**/*.json` | `build:tokens` | All JSON tokens output as Sass maps (excluding keyframe animations) |

For icons, `build:images` generates icon data by recursively reading the file system, mapping subfolder names to object names and file contents to property data. The icon bundle is generated separately because it's very large and should be selectively and lazily loaded.

`build:tokens` uses Style Dictionary to transform [spec-compliant JSON tokens](https://www.designtokens.org/tr/2025.10/) into different formats, including Sass and CSS.
